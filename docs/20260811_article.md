# 中文译文

迈尔博士是一位研究人们在大型系统中如何生活的**社会学家**。她对一座叫北门的**制造业****工业**小镇感到**好奇**。在镇上**典礼**的一次简短**介绍**后，她决定在那**居住**一个季节。

"我不会**高估**自己能这么快学到的东西，"她告诉自己的**院系**导师。"但我会**识别**日常工作的真实**品质**。"导师给了一笔小额**奖学金**资助这趟行程。迈尔**迎接**这个消息时满是**惊异**。

在工厂里，她成了一名安静的**观察者**。"**观察者**必须**隐藏**一切、并**尊重**每一个**个体**，"她写道。**众多**工人加入了她的研究。工厂生产**玻璃**和**毛衣**。当一台机器开始**崩溃**时，一个**轻微的**故障**出现**了。团队没有**惊慌**；他们用**合适的**工具迅速**修理**，并且在压力下会**展现**冷静。

工作遵循类**军事**的**规则**。"我们**服从**规则，因为它**保证**安全，"一名工人说。一名**债务人**开始**拖欠**付款，引发了一场**冲突**。**经理**保持**冷静**并**协商**出一个公平的方案；他们学会了一起**攻击**这个问题。这份**体谅**让整个团队保持**参与**。

一名叫本的工人有慢性背痛。每天的**费力**让他在冷天感到**痛苦**。他**很少****抱怨**，并**乐意**帮忙搬运沉重的**库存**。他的**配偶**每晚**迎接**他。"家庭是我真正的**力量**，"本说。迈尔注意到，这里的**肥胖**和**肿瘤**风险比平均水平**相当****低**，也许是因为清洁的**气候**。

她看到当机器**失灵**时，工人变得多么**脆弱**。一个小**错误**就可能**伤害**手。她看到一个男人**抓**起一个热的零件并**踢**响警报。"别**分散**产线注意力，"前来**监督**的**主管**喊道。尽管有**苦难**，这班组仍保持善意。

**除了**安全，她还研究学习。新员工必须**检查**每个零件。**考核**持续了**第八**周。他们**打印**手册并**放置**在货架的每一**层**。"我们靠做来**获得**技能，"**专家**们说。

有句**陈词滥调**说工厂工作无聊。但迈尔发现它很有**创造性**。工人们**想出**聪明的修法，新旧方法的**融合**由此达成。一个**模仿**工具为工厂省下了**大量**钱。**零售商**感到**惊奇**。"这是真正进步的**成分**，"他说，列举了各**种**想法。

她还遇到一名感到**紧张**的**少数族裔**工人，他对**认知**测试紧张。"我紧张时常常**放错**我的词，"他说。迈尔为他在**裁缝**式地调整了问题。在一次**随意**的聊天后他**振作**起来，并感到**稍微**更自信。

她观察了一项**激素**研究：容易**悲伤**的工人情绪**滞后**。当地**头条**称北门为"模范工厂"。迈尔**迎接**这份**即将出台**的报告，满心希望。一些**债务人****落后**了，但工厂**继续**谨慎前行。
